
## 🎯 Что это?

Это приложение, где централизованно собираются вопросы, которые преподаватели задают при сдаче лабораторных работ. Данные хранятся в **GitHub Issues**.

## 📝 Как добавить вопрос?

### Способ 1: Через кнопку на сайте (рекомендуется)

1. На сайте нажми **"➕ Добавить вопрос"**
2. Откроется форма создания GitHub Issue с предзаполненными полями
3. Заполни вопрос в markdown
4. Нажми "Create issue"

### Способ 2: Вручную на GitHub

1. Перейди в Issues репозитория
2. Нажми "New issue"
3. Используй эту структуру:

```markdown
Вопрос: Что такое внешний ключ?

Кому задавался: P3118

Дата: 2026-02-03

Ответ студента: хз (опционально)

Оценка ответа: допса (опционально)
```

4. **Обязательно добавь labels (без них вопрос не появится на сайте):**
   - `subject:БД` или `subject:Программирование` или `subject:ОПД`
   - `lab:1`, `lab:2` и т.д.
   - `status:pending` (для модерации)



## ⚠️ Ограничения:

- GitHub API имеет rate limit: 60 запросов в час без авторизации
- Если превышить — нужна авторизация (но я это не рекомендую)


## 🚨 Часто встречающиеся ошибки

### Issue не появляется на сайте

**Проверь:**
- ✅ Label `status:approved`? 
- ✅ Правильный label `subject:*`?
- ✅ Правильный label `lab:*`?
- ✅ Issue открыт (не закрыт)?
